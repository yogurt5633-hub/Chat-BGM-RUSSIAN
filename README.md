# 🎵 Chat BGM

Расширение для SillyTavern. Анализирует последние сообщения чата, подбирает музыку под атмосферу сцены и воспроизводит официальные записи с YouTube.

- Рекомендует композиции **только в жанрах, отмеченных в настройках**.
- Ищет официальные аудиозаписи (каналы артистов Topic, Official Audio) и видео с официальных каналов. Отфильтровывает каверы, концертные записи, ремиксы и часовые повторы.
- Через заданное число ответов персонажа повторно анализирует сцену и подбирает музыку под изменившуюся атмосферу.

![Плеер: рекомендации и история воспроизведения](docs/player.png)

## Установка

В SillyTavern откройте **Расширения → Установить расширение** и вставьте адрес репозитория:

```
https://github.com/STLoft/Chat-BGM
```

## Подготовка: API-ключ YouTube

Для поиска композиций на YouTube требуется ключ YouTube Data API v3. В стандартных пределах использование бесплатное, без обязательного добавления платёжных реквизитов. Настройка обычно занимает несколько минут.

1. Войдите в [Google Cloud Console](https://console.cloud.google.com/) под учётной записью Google.
2. Нажмите на название проекта в верхней части страницы. Выберите существующий или создайте **Новый проект** с любым названием.
3. Перейдите в **API и сервисы → Библиотека**, найдите `YouTube Data API v3` и нажмите **Включить**.
4. В разделе **API и сервисы → Учётные данные** нажмите **Создать учётные данные → API-ключ**. Скопируйте ключ, начинающийся с `AIza`.
5. Откройте настройки созданного ключа и в разделе **Ограничения API** выберите ограничение только на `YouTube Data API v3`. Сохраните изменения.
6. В SillyTavern вставьте ключ в **Настройки расширений → 🎵 Chat BGM → Ключ YouTube Data API v3**.

Важно:

- **Ограничения приложения оставьте в положении «Нет».** Если ограничить ключ веб-сайтами, потребуется правильно указать каждый адрес доступа к SillyTavern, в том числе на телефоне.
- **Не используйте API-ключ от других проектов.** Ключ хранится в настройках SillyTavern и передаётся браузером при поиске. Рекомендуется создать отдельный ключ только для этого расширения и ограничить его YouTube Data API v3. Можно использовать существующий проект Google Cloud, но API нужно включить именно в этом проекте.
- Сразу после создания ключа в течение нескольких минут возможна ошибка его проверки. Попробуйте ещё раз позднее.
- Google может изменять названия и расположение разделов консоли.

### Квота API

По умолчанию YouTube Data API выделяет каждому проекту **10 000 единиц в день**. Один поисковый запрос расходует **100 единиц**, то есть можно найти около 100 новых композиций в день.

| Расходует квоту | Не расходует квоту |
| --- | --- |
| Первый поиск композиции: 100 единиц | Повторное воспроизведение уже найденной композиции |
| Поиск следующего варианта, если официальный трек не найден: по 100 единиц | Воспроизведение из истории, избранного ★ или карточки, если видео уже найдено |
| Поиск альтернативного видео при блокировке воспроизведения: ещё 100 единиц (можно отключить) | Воспроизведение видео через вкладку **По ссылке** |
| | Воспроизведение, пауза и отображение миниатюр |
| | Запрос рекомендации у модели (расход токенов модели учитывается отдельно) |

- Расширение ищет не все предложенные композиции сразу, а только очередную для воспроизведения.
- Кеширует результаты поиска для последних 300 композиций. Кнопка **Очистить историю и кеш поиска** удаляет кеш, после чего повторный поиск той же композиции снова расходует квоту.
- При исчерпании дневного лимита можно воспроизводить только ранее найденные композиции. Квота обновляется в полночь по тихоокеанскому времени США.
- Использование квоты можно посмотреть в Google Cloud Console: **API и сервисы → Включённые API и сервисы → YouTube Data API v3 → Квоты**.
- Квота назначается проекту, а не отдельному ключу. Несколько ключей одного проекта не увеличивают лимит.
- Для экономии увеличьте интервал повторного анализа сцены или отмечайте понравившиеся треки звездой и используйте **Повтор избранного ★**.

Без API-ключа модель всё равно может рекомендовать музыку. При нажатии на название композиции откроется поиск YouTube. Во вкладке **По ссылке** можно воспроизводить видео по URL без ключа.

## Использование

1. Откройте **Настройки расширений → 🎵 Chat BGM** и отметьте желаемые жанры.
2. Нажмите на значок 🎵 в панели Quick Reply (быстрых ответов). Расширение проанализирует текущую сцену и включит подходящую музыку.

| Действие | Результат |
| --- | --- |
| Нажать 🎵 | Если музыка не играет — подбор и воспроизведение. Если играет — пауза / продолжить |
| Удерживать 🎵 (на ПК — правая кнопка мыши) | Открыть или закрыть плеер |
| Нажать 🎵 у сообщения (в меню действий ⋯) | Подобрать музыку по диалогу до выбранного сообщения включительно, в том числе по скрытым сообщениям |
| Выбрать Chat BGM в меню расширений (значок волшебной палочки) | Открыть или закрыть плеер |

Если Quick Reply не используется, значок помещается в панель слева от поля ввода. Местоположение настраивается в разделе **Положение значка**: номер набора быстрых ответов и позиция внутри набора.

В плеере находятся видео, кнопки управления и вкладки **Рекомендации** (композиции в очереди), **По ссылке** и **История воспроизведения** (до 100 последних треков). Нажатие на композицию запускает её. Для треков в истории используется найденное ранее видео. При закрытии плеера музыка продолжает играть; для остановки нажмите ■. Плеер можно перетаскивать за заголовок.

- **По ссылке:** вставьте прямой URL YouTube. Поддерживаются обычные ссылки, `youtu.be`, YouTube Music и Shorts. Квота поиска не расходуется. В историю записывается название видео.
- **Звёздочка ☆ в истории:** избранная композиция сохраняется после очистки истории и не удаляется при достижении лимита 100 треков.
- **Стрелка → в истории:** добавляет карточку композиции к выбранному сообщению (см. [Музыкальные карточки](#музыкальные-карточки)).
- **Кнопка 🔁:** переключает режимы «Без повтора → Повтор одной композиции → Повтор избранного ★».
- **Открыть на YouTube:** команды «Открыть все рекомендации на YouTube» и «Открыть избранное ★ на YouTube» создают временный плейлист (до 50 видео). В рекомендациях текущая композиция ставится первой. На телефоне откроется приложение YouTube. Если некоторые видео ещё не найдены, сначала потребуется поиск с расходом квоты — затем нажмите кнопку снова. После открытия YouTube расширение больше не управляет переключением композиций там.

### Прослушивание в фоне

Встроенный плеер работает, пока активна страница SillyTavern. Для воспроизведения с выключенным экраном или при использовании другого приложения необходимо открыть музыку в приложении YouTube; для фонового воспроизведения там обычно требуется **YouTube Premium**.

## Музыкальные карточки

Если включить настройку **Каждые N ответов персонажа добавлять музыкальную карточку**, модель выбирает подходящую композицию и дописывает специальный тег в конце каждого N-го ответа (по умолчанию каждые 6 ответов). Карточка появляется **в начале сообщения**. Нажатие на неё запускает музыку или ставит на паузу.

Музыку, рекомендованную кнопкой 🎵 рядом с сообщением, также можно сохранить как карточку в этом сообщении (отключается в настройках). Это работает и со старыми или скрытыми сообщениями. Такая карточка сохраняется в дополнительных данных чата, не меняя текст сообщения.

Чтобы прикрепить композицию из истории к другому сообщению или заменить существующую карточку, нажмите → возле композиции в истории и укажите номер сообщения.

Удерживайте карточку (на ПК — правая кнопка мыши), чтобы открыть меню:

- **Открыть на YouTube:** открыть видео в YouTube. Если композиция ещё не воспроизводилась, откроется страница поиска. После перехода в YouTube расширение не управляет дальнейшим воспроизведением.
- **Удалить карточку:** удалить карточку. Если её создала модель через тег `<bgm …>`, тег будет удалён и из текста сообщения — отменить это действие автоматически нельзя. Тег также можно удалить при ручном редактировании сообщения.

В настройках доступны пять видов карточек: **Капсула, Мини-плеер, Одна строка, Виниловая пластинка, Шкала прогресса**. Мини-плеер и виниловая пластинка показывают миниатюру YouTube для композиции, которая уже воспроизводилась.

![Пять видов музыкальных карточек](docs/cards.png)

- Дополнительный запрос к модели для карточки не требуется. Вместо этого к промпту соответствующего ответа добавляется инструкция и список допустимых жанров. Значение N = 1 добавляет карточку к каждому ответу персонажа.
- Этот интервал не связан с настройкой повторного анализа сцены, которая отдельно обращается к модели во время воспроизведения музыки.
- Строка `<bgm …>` скрывается в интерфейсе, но остаётся в тексте сообщения и может попадать в последующий контекст модели.
- Композиция вне выбранных жанров не отображается как карточка.

## Настройки

| Параметр | Описание |
| --- | --- |
| **Положение значка** | Набор быстрых ответов: 0 — последний, 1 — первый, 2 — второй. Позиция внутри набора: 0 — в конце, 1 — в начале, 2 — второй значок. |
| **Жанры** | Рекомендации только в отмеченных жанрах. Можно добавить собственные жанры через запятую. |
| **Только инструментальная музыка** | Подбирать композиции без вокала. |
| **Только официальное аудио и видео с официальных каналов** | Пропускать видео, официальный статус которых не подтверждён. |
| **Искать другое видео, если воспроизведение заблокировано** | Искать альтернативное официальное видео (по умолчанию включено; ещё 100 единиц квоты на трек) или пропускать композицию на этом устройстве. |
| **Подключение для анализа** | При каждой рекомендации вызывается выбранная модель. Пустое значение — активная модель SillyTavern. |
| **Анализировать сцену каждые N ответов персонажа** | Во время воспроизведения музыки подбирать новые композиции по развитию сцены. |
| **Сразу переключаться на новую композицию** | Если выключено, новая композиция включается после завершения текущей. |
| **Число сообщений для анализа** | Сколько последних сообщений передавать модели (по умолчанию 12). |
| **Композиций за один подбор** | Сколько вариантов запрашивать у модели (по умолчанию 4). Первый запускается, остальные находятся в очереди. |
| **Добавлять музыкальную карточку каждые N ответов** | Модель выбирает музыку для каждого N-го ответа (по умолчанию 6; значение 1 — для каждого ответа). |
| **Вид карточки** | Капсула, Мини-плеер, Одна строка, Виниловая пластинка, Шкала прогресса. |
| **Автоматически включать музыку при получении ответа с карточкой** | Если выключено, воспроизведение начинается только при нажатии на карточку. |
| **Добавлять карточку при нажатии 🎵 у сообщения** | Если выключено, рекомендация воспроизводится, но не прикрепляется к сообщению. |
| **Очистить историю и кеш поиска** | Удаляет историю и кеш найденных видео, сохраняя композиции со звездой. |
| **Когда композиция закончится** | «Следующая рекомендация» — перейти к другому варианту или запросить новую подборку; «Повтор одной композиции» — повторять текущую; «Повтор избранного ★» — циклически воспроизводить композиции со звездой. При повторе автоматический анализ через N ответов приостанавливается. |

## Примечания

- Браузер может блокировать воспроизведение звука без действия пользователя. В этом случае нажмите 🎵.
- На **iPhone и iPad** автоматический запуск видео обычно недоступен: откройте плеер и нажмите на само видео. Громкость регулируется кнопками устройства, а не ползунком плеера. При выключении экрана или переключении приложения воспроизведение останавливается.
- Перед композицией YouTube может показывать рекламу. Для пропуска откройте плеер и нажмите кнопку пропуска непосредственно в видео.
- На телефоне воспроизведение YouTube прерывается при выключении экрана или уходе браузера в фон.
- **Для фонового прослушивания в приложении YouTube необходим YouTube Premium.** Откройте композицию через «Открыть на YouTube» и используйте аккаунт с Premium. Встроенный плеер расширения не воспроизводит музыку в фоне даже при наличии Premium.
- Правообладатели некоторых записей запрещают встраивание на сторонних сайтах; доступность также зависит от устройства и браузера. Расширение запоминает заблокированные видео только для текущего устройства. При включённой настройке альтернативного видео делает ещё один поиск официальной версии (100 единиц квоты), иначе переходит к следующей композиции. Для вручную выбранной композиции сообщает код ошибки YouTube и показывает ссылку **Открыть на YouTube** вместо автоматического переключения.
- Если модель придумает несуществующую композицию, YouTube не найдёт её и расширение перейдёт к следующему варианту.
- **Ошибка YouTube 153:** YouTube не может определить сайт, в который встроен плеер. Расширение настроено передавать данные об источнике только плееру; если ошибка сохраняется, оно пересоздаёт плеер и повторяет попытку.
